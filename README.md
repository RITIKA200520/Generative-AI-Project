# Generative AI Project

## About the Project

This repository contains my practical learning and implementation of Generative AI concepts using Python. The project focuses on exploring different language models, developing AI-powered chatbots, and understanding text embedding techniques.

I created this project to strengthen my understanding of Generative AI and gain hands-on experience with AI tools and technologies.

## Technologies Used

- Python
- LangChain
- Generative AI Models
- Hugging Face
- Streamlit
- UV (Python Package Manager)

## Project Modules

**1. Chat Models**
- Exploring different language models.
- Implementing conversational AI applications.
- Developing an interactive chatbot interface.

**2. Embedding Models**
- Exploring text embedding techniques.
- Working with Hugging Face embedding models.
- Understanding how text can be represented as numerical vectors.

## Project Structure

The repository is organized into separate folders for chat models, embedding models, and application source code to keep the project organized and easy to understand.
